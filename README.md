# Telegram-бот экскурсии «От посикунчиков до Пермских богов»

MVP Telegram-бота для интерактивной экскурсии по Перми. Бот спрашивает имя участника, ведёт по 5 точкам маршрута, даёт короткие задания, запускает финальный квиз и выдаёт текстовый «Паспорт пермяка».

## Как создать бота через BotFather

1. Откройте Telegram и найдите `@BotFather`.
2. Отправьте команду `/newbot`.
3. Укажите название бота.
4. Укажите username бота, который заканчивается на `bot`.
5. BotFather выдаст токен. Он нужен для запуска проекта.

## Настройка окружения

Создайте виртуальное окружение и установите зависимости:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Для Windows активация окружения выглядит так:

```bash
.venv\Scripts\activate
```

Создайте файл `.env` из примера:

```bash
cp .env.example .env
```

Откройте `.env` и вставьте настоящий токен:

```env
BOT_TOKEN=токен_от_BotFather
```

## Запуск

```bash
python main.py
```

После запуска откройте своего бота в Telegram и отправьте `/start`.

## Как пройти маршрут

1. Нажмите «Начать маршрут».
2. Введите имя.
3. Проходите 5 точек маршрута по порядку.
4. На каждой точке отвечайте на вопрос через кнопки.
5. После пятой точки нажмите «Начать квиз».
6. Ответьте на 5 вопросов.
7. Нажмите «Получить паспорт пермяка».

## Перезапуск сценария

Команда `/restart` полностью очищает состояние пользователя и запускает сценарий заново. В финале также есть кнопка «Пройти маршрут заново».

```text
│   ├── route.py

│   ├── route.py
│   ├── quiz.py
│   └── fallback.py

    └── passport.py
```

Тексты маршрута и квиза лежат отдельно в `data/`, поэтому сценарий можно дорабатывать без изменения основной логики бота.
